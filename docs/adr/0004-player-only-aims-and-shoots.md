# The player only aims and shoots; the character moves on its own

Like a mall arcade light-gun shooter, the player never steers the character. It moves through the Room by itself, and the player's whole job is aiming, shooting, reloading, throwing Grenades and using Skills. We picked this over twin-stick controls because one hand (or one finger) aiming in the dark is the core of the game, and it frees the touch screen for gestures instead of a movement stick. It also means nothing in the design may depend on the player dodging: threats have to be answerable by shooting.

Amended by [ADR 0006](0006-relocate-in-boss-fights.md): Boss fights that call for it allow one discrete movement choice, Relocate.
