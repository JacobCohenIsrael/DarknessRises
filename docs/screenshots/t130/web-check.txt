# So on itch.io vibrate works once the player has tapped inside the game's frame, which the first shot or button
# press is. Before that Chrome refuses it with a console error; WebHaptics.jslib checks
# navigator.userActivation.hasBeenActive first and skips quietly instead. On a desktop browser (no touch screen) and on
# iOS Safari (no navigator.vibrate) the device reports it can't vibrate: nothing is called and the switch is hidden.
