Issue #78, slice 5: switching Primary weapons mid-Run, with finite ammo. Headless check.

A batch-mode Editor (no window, master volume 0) played from the boot scene. This time the probe went through real
input devices: a touchscreen it added and touched (so the event system, the UI filter and the Gesture input saw a
finger), a keyboard and a mouse. It read the Run's loadout and the HUD's texts back after every step. Test saves
were written to the player's normal save path and deleted afterwards.
