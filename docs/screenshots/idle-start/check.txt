"The game starts idle" on 0.1.15: reproduction and fix. Headless check.

The exact release zip (Builds/WebGL/DarknessRises-0.1.15-webgl.zip, copied, not moved) was unzipped and served by a
small Node server at http://127.0.0.1:8377, and run in Chrome 157 in headless mode: muted, no window, on the real GPU,
driven through the DevTools protocol. Every run used a browser profile that had never seen the game. A screenshot of
the game's canvas was taken every second and read by a script; the whole console, every exception and every failed
request went to a file (console-0.1.15-embedded.txt is the embedded run's).

"IDLE" below is the frame in the user's report: the character standing in its Aura, SCORE 0, "PISTOL / RESERVE 0",
12 / 12, the Q FLARE and E SLOW-MO buttons, one hit point pip, one Grenade dot, no title card.

WHAT IT IS
  The Level scene is shown the moment the scene itself has loaded. Its content (the Enemies, their sounds: about
  10 MB of Addressables bundles) is still downloading then, and the Level only starts (its HUD filled in, the title
  card, the walk) once that is in. Until it is, the scene shows what it was built with. On a local server that is one
  frame in thirty; on a real connection, on the first visit to a new upload, it is seconds.
  Nothing stalls and nothing throws: no exception, no "[Save]" line, no failed request from the game in any run.
