Issue #113: the loading screen's download bar. Headless check.

This branch built as a release WebGL 0.1.16 (PlayerBuilds.BuildWebGL), served by a small Node server at 127.0.0.1 that
answers like a real host (ETag and Last-Modified, 304 for a file the browser already has) and counts what it sends.
Chrome 157 in headless mode, muted, no window, on the real GPU (WebGPU), driven over the DevTools protocol, throttled
to 1024 KB/s (8 Mbit/s) with 40 ms latency. Every scenario starts from a browser profile that has never seen the game.

The bar's value is read off the screen: every half second the canvas is captured and the bar's lit row measured
(the filled part is bright, the rest barely lit). "over the wire" is what Chrome received for Addressables bundles.
Time counts from the moment Unity's own loader is done (the engine has started; its splash comes first).

States: splash = Unity's "Made with Unity"; black; label = LOADING with dots, no bar; bar NN% = the download bar;
level = the Level's HUD (Stage 1); shop = the Shop screen; other = lit, with no label (the version label on black,
or the Shop fading out).
