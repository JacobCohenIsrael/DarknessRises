# Endless Ramp, Shop only between Runs

A Run has no breaks: Waves of Enemies keep arriving and grow over time (the Ramp) until the player dies or leaves. The Shop opens only between Runs, so all meta progression (Credits, weapon upgrades, skill tree) happens outside the Room. We picked this over waves with a calm and a shop between them so the tension never lets up inside a Run, and to keep the core loop separate from the meta layer that comes later.

Superseded by [ADR 0005](0005-endless-chain-of-levels.md): a Run is now an endless chain of Levels, each ending with a Boss. The Shop-between-Runs rule carries over.
