Issue #110: keep player data across Web builds. Headless check.

Web builds were served from several URL paths of one local origin (http://127.0.0.1:8377) by a small Node server,
as itch.io serves each upload from a new path of one origin. They ran in Chrome 157 in headless mode, muted, on the
real GPU (WebGPU, 60 frames a second), driven through the DevTools protocol: no window was ever shown. Each scenario
used a browser profile of its own that had never seen the game. A Run was played for real with the mouse: the script
looks at a screenshot, aims at the nearest pair of glowing eyes and holds Fire until the character dies and the
CONTINUE? countdown runs out. "IndexedDB files" lists what Unity put in its file system database (/idbfs).

BEFORE: build 0.1.14 as published, at /upload-1/ and /upload-2/
  first visit to /upload-1/                -> Stage 1. localStorage {} | IndexedDB files []
  a Run: 1 Enemy killed, to the Shop       -> the Shop shows CREDITS 5. localStorage {} | IndexedDB files []
  /upload-1/ reloaded                      -> Stage 1 again, 0 Credits. The save was never put in the browser.
  /upload-2/                               -> Stage 1, 0 Credits.
